ChatRite start sheet

Everything for starting and running ChatRite on the RTX 4080 laptop at home. The three programs run on that laptop only. Nothing here leaves it.

Start it, in this order

  1. Ollama (the model that does the thinking) Press the Windows key, type Ollama, press Enter. You should see a llama icon by the clock, under the up arrow if it is hidden. Leave it running. If it is already there, skip this.
  2. ChatRite (word fixing and polish) Press Windows key + R, type shell:startup, press Enter, then double-click ChatRite. You should see a black starburst icon by the clock.
  3. ChatRite Dictate (voice typing) In the same folder, double-click ChatRite Dictate. A grey ring appears. The first start of the day takes a few seconds while it loads the speech model. It is ready when the tooltip stops saying "loading".

If the Startup folder is empty, download ChatRite again from the set-up page below and run it. It puts itself back in the folder.

What to press and say

Do thisTo get this
Ctrl+Shift+SpaceFix wrong words in the selected text, or the whole box if nothing is selected.
Ctrl+Shift+Alt+SpacePolish: full stops, commas and capitals, without rewording. Ctrl+Z undoes it.
Ctrl+Alt+SpaceStart or stop voice typing. It switches itself off after 90 seconds of quiet.
Say "polish"Polish what you have just dictated. Say it alone, after a pause.
Say "full stop", "comma", "question mark", "exclamation mark"Types that punctuation mark.
Say "new line", "new paragraph"Line break, or a gap between paragraphs. Never sends a chat message.
Say "stop dictation"Switches voice typing off.

Press Windows key + R, paste a path and press Enter.

If something is wrong

What you seeWhat to do
"Could not reach Ollama"Start Ollama (step 1). To check it, open http://127.0.0.1:11434 in a browser on the laptop. It should say "Ollama is running".
The grey ring disappeared after an updateOpen Windows key + R, shell:startup, double-click ChatRite Dictate. This should no longer happen on updates now.
Saying "polish" does nothingCheck ChatRite (the starburst) is running and shows Version 10 or later. Update both programs: starburst first, then the ring, each with "Check for updates now".
The ring says "loading" for minutesOnly the very first start downloads the model. After that it takes seconds. If it stays stuck, send the last lines of the voice typing log to Claude.
Full stops in odd placesSay "polish" at the end, or press the polish keys. The live full stops are a rough first pass.

To update: right-click the starburst, choose "Check for updates now", wait for it to reload. Then do the same on the grey ring. Starburst first.
