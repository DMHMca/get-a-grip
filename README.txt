Get a grip - files for GitHub Pages

Upload every file in this folder (not the zip itself) to the top level of your repository:
  index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png, icon-maskable-512.png, apple-touch-icon.png

Then in the repository: Settings > Pages > Source: Deploy from a branch > main / (root) > Save.
After a minute the app is at https://YOURUSERNAME.github.io/REPOSITORYNAME/
Open that address in Chrome on your phone, then menu > Install app.

To update later: upload the new files over the old ones (same names). Open the app once with a
connection and it picks the new version up; close and reopen if you don't see it straight away.

Version 2 adds: Activities page > Import from Google Tasks (one-off import, needs a Google client ID).
