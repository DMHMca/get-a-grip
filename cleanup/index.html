ChatRite

Press Ctrl+Shift+Space in any text box and it fixes speech-to-text mistakes (whole or hole, Codex or Kodak's, doubled words) using a language model that runs on your own PC. Nothing leaves the PC. It updates itself.

1. Install AutoHotkey (once)

Download the version 2 installer and run it with the standard options.

AutoHotkey download page

2. Install Ollama (once)

This runs the language model on your graphics card. Run the installer. It then sits by the clock.

Ollama for Windows

3. Get the tidy script (once)

Download it and double-click it. Chrome may say the file is uncommon: choose Keep. The first time, it offers to download the language model (a few gigabytes) and puts itself in Windows Startup.

Download cleanup.ahk

After that, right-click its icon by the clock and choose Try it on a sample sentence. It tells you how long it took.

Updates arrive by themselves from this page. Your own words and names are in the vocabulary file (tray menu: Edit my words and names).
